## 1. 项目概述

### 1.1 项目背景

随着数码设备拍摄的普及，用户面临着日益增长的照片管理难题。照片分散存储在SD卡、手机、U盘等多个设备中，缺乏统一的整理工具。本项目旨在开发一款高效、易用的桌面照片整理程序，帮助用户自动化整理照片，提升照片管理效率。

### 1.2 项目目标

开发一款Windows桌面照片整理程序，具备以下核心能力：
- 支持多种设备（SD卡、Android、iOS）的照片导入
- 自动识别照片元数据，按日期、设备、类型智能分类
- 提供灵活的导出功能和自定义整理规则
- 友好的用户界面，操作简便

### 1.3 使用场景

**目标用户**：个人用户，用于整理家庭照片、旅行照片、日常拍摄等个人照片资源。

## 2. 功能需求

### 2.1 照片导入功能

#### 2.1.1 支持的导入源

| 导入源 | 支持方式 | 说明 |
|--------|----------|------|
| SD卡/USB存储 | 自动检测 | 自动识别连接的外部存储设备 |
| Android设备 | MTP协议 | 通过MTP协议连接Android设备 |
| iOS设备 | iTunes/AFC协议 | 通过iTunes协议连接iOS设备 |
| 本地文件夹 | 文件选择/拖拽 | 选择本地文件夹或拖拽文件 |

#### 2.1.2 导入流程

1. **设备连接检测**：自动扫描并显示可用的导入源
2. **预览选择**：显示可导入的照片/视频缩略图，支持选择性导入
3. **导入确认**：显示导入摘要，确认后开始导入
4. **导入进度**：实时显示导入进度，支持取消操作
5. **导入完成**：显示导入结果摘要

#### 2.1.3 导入限制

- 支持的图片格式：JPG、JPEG、PNG、GIF、BMP、TIFF、WebP、RAW（CR2/NEF/ARW等）
- 支持的视频格式：MP4、MOV、AVI、MKV、WMV
- 单次导入文件数量上限：10000个文件
- 支持的最大文件大小：单文件4GB

### 2.2 智能整理功能

#### 2.2.1 自动整理规则

**日期分类**：
- 按拍摄日期创建文件夹结构：`年/月/日`
- 支持按年或年月两种分类深度
- 无法识别日期的照片放置在"未分类"文件夹

**设备分类**：
- 根据EXIF中的相机/手机型号识别设备
- 按设备品牌和型号创建子文件夹
- 无法识别设备的照片放置在"其他设备"文件夹

**文件类型分类**：
- 照片与视频分别存储
- 按文件扩展名进一步细分

#### 2.2.2 自定义整理规则

用户可配置的选项：
- 目标文件夹根目录
- 文件夹命名格式（如`YYYY-MM-DD`或`YYYY年MM月DD日`）
- 是否启用设备分类
- 是否启用文件类型分类
- 重命名规则（可选）

#### 2.2.3 重复检测

- 基于文件大小+文件名的重复检测
- 基于EXIF拍摄时间+文件名的重复检测（可选）
- 重复文件提示和处理（删除/跳过/保留）

### 2.3 照片管理功能

#### 2.3.1 图库浏览

- 网格视图：显示照片缩略图
- 列表视图：显示照片详细信息
- 支持缩略图大小调节
- 支持按日期、设备、文件夹筛选

#### 2.3.2 照片预览

- 双击打开照片详情
- 支持放大/缩小、拖拽浏览
- 显示EXIF信息面板
- 快捷键支持（J/K导航、ESC关闭）

#### 2.3.3 元数据查看

显示的EXIF信息：
- 拍摄时间
- 相机/手机型号
- 镜头信息（如适用）
- 拍摄参数（光圈、快门、ISO）
- GPS位置（如有）
- 文件大小、分辨率

#### 2.3.4 批量操作

- 批量重命名：支持按规则批量重命名
- 批量移动：移动选中照片到指定文件夹
- 批量删除：删除选中照片（移至回收站）

### 2.4 导出功能

#### 2.4.1 导出选项

- **路径选择**：用户自定义导出目标路径
- **保留结构**：可选择是否保留整理后的文件夹结构
- **格式转换**：可选将RAW格式转换为JPG
- **压缩选项**：可选压缩导出，设置压缩质量
- **元数据处理**：可选保留或删除EXIF信息

#### 2.4.2 导出流程

1. 选择导出内容（全选/按条件筛选/手动选择）
2. 选择导出选项
3. 确认导出摘要
4. 执行导出，显示进度
5. 导出完成，显示结果

### 3.4 IPC通信接口

#### 主进程 → 渲染进程

| 事件名 | 参数 | 说明 |
|--------|------|------|
| `device:connected` | { devices: Device[] } | 新设备连接 |
| `device:disconnected` | { deviceId: string } | 设备断开 |
| `import:progress` | { current: number, total: number, file: string } | 导入进度 |
| `import:complete` | { success: number, failed: number } | 导入完成 |
| `organize:progress` | { current: number, total: number } | 整理进度 |

#### 渲染进程 → 主进程

| 方法名 | 参数 | 返回值 | 说明 |
|--------|------|--------|------|
| `devices:list` | - | Device[] | 获取设备列表 |
| `devices:readDir` | { deviceId: string, path: string } | File[] | 读取设备目录 |
| `import:start` | { deviceId: string, paths: string[], options: ImportOptions } | void | 开始导入 |
| `import:cancel` | - | void | 取消导入 |
| `organize:start` | { files: string[], rules: OrganizeRules } | void | 开始整理 |
| `files:getExif` | { filePath: string } | ExifData | 获取EXIF信息 |
| `files:preview` | { filePath: string } | string (base64) | 获取预览图 |
| `dialog:selectFolder` | - | string \| null | 选择文件夹 |

## 5. 数据流程

### 5.1 导入流程

```
用户选择设备
    ↓
读取设备文件列表
    ↓
显示可导入文件预览
    ↓
用户选择文件 + 配置选项
    ↓
复制文件到临时目录（同时提取EXIF）
    ↓
应用整理规则（如启用）
    ↓
移动到最终目录
    ↓
更新图库索引
    ↓
导入完成
```

### 5.2 整理流程

```
读取源文件EXIF信息
    ↓
根据规则生成分类信息
    ↓
检测重复文件
    ↓
显示整理预览
    ↓
用户确认
    ↓
执行文件移动/重命名
    ↓
更新数据库索引
    ↓
整理完成
```

## 6. 错误处理

### 6.1 错误类型

| 错误类型 | 处理方式 | 用户提示 |
|----------|----------|----------|
| 设备断开 | 暂停操作，提示用户重新连接 | "设备已断开，请重新连接" |
| 文件读取失败 | 跳过该文件，继续处理其他文件 | 显示失败文件列表 |
| 磁盘空间不足 | 停止操作，提示用户清理空间 | "磁盘空间不足，请清理后重试" |
| 文件权限不足 | 跳过该文件，提示权限问题 | "部分文件无法访问" |
| 文件格式不支持 | 跳过该文件 | 显示不支持的文件列表 |
| 目标路径不存在 | 创建目录或提示用户 | 自动创建或提示选择有效路径 |

### 6.2 异常恢复

- 导入过程中断：保存导入进度，支持断点续传
- 整理操作可逆：保留原文件或提供撤销功能
- 定期自动保存应用状态
